# miaoyue-ijhci-dataset-access
Data access information for the ijhci paper

## Study title

A Person-in-Context Analysis of Engagement in Technology-Supported Field-Based Learning: ICAP Configurations, Across-Activity Profiles, and Meaning-Making

## Data description

This study includes questionnaire responses, written responses, and focus-group interview data collected from secondary school students.

## Data availability

Individual-level data are not publicly accessible to protect participant confidentiality. Access requests will be considered in accordance with participant consent and applicable institutional requirements.

## Requesting access

Researchers seeking access should contact the corresponding author, specifying the data requested and the proposed research use.
