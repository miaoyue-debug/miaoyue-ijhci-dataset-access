Data access information

This repository provides data access information for a manuscript submitted to the International Journal of Human–Computer Interaction.

Data description

This study includes questionnaire responses, written responses, and focus-group interview data collected from secondary school students.

Data availability

The underlying data are not publicly accessible in decrypted form to protect participant confidentiality. Access to the decrypted data should be requested from the corresponding author. Requests will be considered in accordance with participant consent and applicable institutional requirements.

Requesting access

Researchers seeking access should contact the corresponding author, specifying the data requested and the proposed research use.
